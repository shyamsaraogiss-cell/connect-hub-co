# Archived Prisma migration lineage

This directory preserves the locally available legacy migration files through
2026-09-04 for audit and recovery evidence. It is not an active or executable
Prisma migration lineage.

Five July migration identities recorded in the database ledger were not
available from trustworthy repository or backup sources and have intentionally
not been reconstructed. Obsolete Booking, Travel Assistance, Service, and
ServiceCategory architecture must not be restored from this archive.

The replacement active lineage begins with
`20260903000000_current_precommercial_baseline`, derived from the live approved
pre-commercial database. The commercial workflow remains the next migration.
